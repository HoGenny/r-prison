# Commit Message Examples

## 1) Feature (기능 추가)
- `Feat: 로그인 API 요청 구현`
- `Feat(auth): 로컬 스토리지에 액세스 토큰 저장`
- `Feat(ui): 제출 시 로딩 인디케이터 추가`

## 2) Fix (버그 수정)
- `Fix: 빈 응답 수신 시 크래시 방지`
- `Fix(map): 리렌더링 시 마커 중복 생성 문제 수정`

## 3) Refactor (코드 구조 개선)
- `Refactor: API 클라이언트를 별도 모듈로 분리`
- `Refactor(ui): 모달 컴포넌트 로직 간소화`

## 4) Docs (문서 작업)
- `Docs: 개발 환경 설정 가이드 추가`
- `Docs: API 엔드포인트 목록 업데이트`

## 5) Chore / Build (기타 잡무 및 빌드)
- `Chore: 불필요한 콘솔 로그 제거`
- `Build: dotenv 라이브러리 의존성 추가`
